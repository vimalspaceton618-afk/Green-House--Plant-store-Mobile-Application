# 🌿 Green House – Plant Store Mobile Application UI/UX Design

## 📖 Project Overview
Green House is a modern mobile application UI/UX design created in Figma for users to browse, search, and purchase indoor and outdoor plants. The design focuses on simplicity, usability, and an attractive shopping experience.

## 🎯 Objectives
- Design a clean and modern mobile interface.
- Improve user experience with easy navigation.
- Organize plant information effectively.
- Create an attractive shopping experience.
- Follow modern UI/UX design principles.

## 🛠️ Tools Used
- Figma
- Google Chrome
- Google Fonts (Poppins)
- Material Icons / Flaticon
- Unsplash / Pixabay

## ✨ Features
- Home Screen
- Plant Categories
- Search Bar
- Product Cards
- Plant Details
- Shopping Cart
- User Profile
- Bottom Navigation
- Clean and Responsive UI

## 📱 Design
The interface is designed using Figma with a modern, minimal, and user-friendly layout for a smooth shopping experience.
